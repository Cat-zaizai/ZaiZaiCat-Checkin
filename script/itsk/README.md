# iTSK 自动签到脚本

iTSK（软天空，www.itsk.com）每日签到脚本，支持多账号、账密自动换新令牌、活动签到日历识别。

## ✨ 功能特性

- 🔐 **多账号支持** - 依次处理配置中的所有账号，账号间随机延迟 5-10 秒
- 🔑 **账密自动换新令牌** - `access_token` 过期时自动用配置的账密登录换新并回写配置，无需手动抓包
- 🎯 **智能判重** - 先查签到面板状态，今日已签到则跳过，不重复请求
- 📅 **双签到模式** - 自动适配活动签到（日历 `sign_status` 判定）与普通签到两种面板结构
- ⏱️ **随机错峰** - 启动后在时间窗口内随机延迟，避开请求高峰
- 📊 **结果推送** - 复用项目统一推送模块，输出奖励与补签提醒

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `main.py` | 主入口，多账号签到编排、令牌换新与结果推送 |
| `api.py` | 接口封装：网关签名、账密登录、签到面板查询、执行签到 |

## ⚙️ 配置说明

账号配置写在项目根目录的 `config/token.json` 的 `itsk` 节点下：

```json
{
  "itsk": {
    "accounts": [
      {
        "account_name": "主号",
        "username": "iTSK 用户名或手机号",
        "password": "iTSK 密码",
        "access_token": "登录后自动获取并回写，可留空",
        "uid": "",
        "user_agent": ""
      }
    ]
  }
}
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `account_name` | 否 | 账号备注名，用于日志和推送显示 |
| `username` | 推荐* | 登录用户名或手机号 |
| `password` | 推荐* | 登录密码 |
| `access_token` | 否 | 访问令牌；留空时首次运行自动账密登录获取并回写 |
| `uid` | 否 | 用户 ID，登录成功后自动回写，无需填写 |
| `user_agent` | 否 | 自定义 UA，一般留空 |

> *`username`/`password` 二选一说明：
> - **配置账密（推荐）**：令牌过期（15 天）自动登录换新，全程免维护
> - **仅配 `access_token`**：令牌过期后脚本无法自动续期，需手动重新抓取
>   （浏览器登录 → F12 → Cookies → `itsk_access_token` 的值，含 `Bearer ` 前缀）
> - **修改密码后**：同步更新配置中的 `password` 即可，令牌无需处理

## 🔍 签到机制说明

iTSK 的签到相关接口（均为 `https://api.itsk.com/webapi` 下）：

| 接口 | 说明 |
|------|------|
| `GET /sign` | 查询签到面板，**只读**，不产生签到 |
| `GET /sign_activity` | **执行签到**，对应前端点击"签到"按钮 |
| `POST /username/login` | 账密登录，返回新令牌（15 天有效），**限流 3 次/分钟** |
| `POST /sign_backdate` | 补签（消耗钻石），脚本不自动调用，仅在结果中提醒可补签天数 |

活动签到面板按日历给出每日状态：`1`=已签（历史）、`2`=错过可补签、`3`=今日已签、`4`=今日可签、`0`=未开放（未来）。活动结束后面板回到普通模式（`status` 0/1），脚本两种模式均支持。

所有请求需携带网关签名头（`X-Request-Timestamp` / `X-Request-Nonce` / `X-Request-Signature`），签名算法为 `SHA1(nonce[0:4] + ts + nonce[28:32] + nonce)`，已封装在 `api.py` 中。

## ❓ 常见问题

- **提示"登录被限流"**：登录接口限流 3 次/分钟，稍后手动再跑一次即可；脚本每账号每次运行最多登录 1 次，不会暴力重试
- **提示"用户名、手机号或密码错误"**：确认账密无误；若刚在官网修改过密码，同步更新配置中的 `password`
- **可补签提醒**：错过签到日的补签会消耗钻石，是否补、补哪天请到官网签到日历手动操作
